# Browser engine packages

KnightScope V12 adds single-thread WebAssembly builds for PlentyChess 8.0 and Stormphrax 8.0. The V12 GitHub Actions workflow downloads the pinned files, verifies SHA-256 hashes and byte sizes, and places them beside this README before creating the ZIP.
