# KnightScope V5\n\nV5 returns to the original KnightScope V1 codebase so the compact finished-game review window and original behaviour remain intact. It refreshes the dashboard and adds a Chess chat tab (offline helper). It retains the original analysis board, customization tools, Stockfish assets and Maia model files.\n\nThe chatbot is rule-based and offline, not a hosted AI service. Included model files do not imply a completed engine adapter. Load the `KnightScope-v5` folder using Chrome → Extensions → Developer mode → Load unpacked.\n
