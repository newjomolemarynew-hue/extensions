# Best Move – Combined Chess Extension

An all-in-one browser extension combining features from Best Move and other chess analysis projects.

## Goals
- Combine useful chess analysis features in one extension.
- Support Chess.com and other websites where possible.
- Include a floating panel with hide/show controls.
- Use keyboard shortcuts.
- Provide post-game analysis and chess learning tools.

## Development
This project is a work in progress. Features and improvements will be added as requirements are finalised.
