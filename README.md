# KnightScope V13

KnightScope V13 preserves the unified game-review flow, adds an interactive Analysis Board practice mode, and bundles Stockfish 19 for position analysis. Maia remains available as an optional live-game move predictor.

See [`KnightScope-v13/README.md`](KnightScope-v13/README.md) for installation and Chess.com-only site access. V12 and earlier versions remain preserved.
