# KnightScope V12

KnightScope V12 preserves the unified game-review flow and now bundles **Stockfish 19 only** for Analysis Board engine analysis. The large PlentyChess and Stormphrax integrations and network data have been removed to make the download much smaller.

See [`KnightScope-v12/README.md`](KnightScope-v12/README.md) for installation and Chess.com-only site access. V11 and earlier versions remain preserved.
