# KnightScope V14

KnightScope V14 keeps the unified game-review flow and interactive Analysis Board practice mode, recommends the best move for both sides unless explicitly disabled, and includes Stockfish 19 plus optional Maia move prediction.

Both engines now have editable numeric strength inputs from 100 to 3200. Maia maps the entered value to the nearest available trained model (1100–1900).

See [`KnightScope-v14/README.md`](KnightScope-v14/README.md) for installation and Chess.com-only site access. V13 and earlier versions remain preserved.
