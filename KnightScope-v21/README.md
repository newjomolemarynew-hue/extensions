# KnightScope V21

V21 focuses on the popup dashboard and post-game review workflow.

## Improvements
- Dashboard tabs support Left/Right and Home/End keyboard navigation.
- Popup messaging has clearer failure states when the Chess.com tab needs refreshing or an extension page cannot open.
- Review loading displays a busy state and prevents repeated clicks.
- Removed the inactive Automatic review checkbox.
- The analysis entry is labelled clearly as the Analysis Board and describes post-game/position exploration.

## Install
1. Download and extract `KnightScope-v20.zip`.
2. Open `chrome://extensions` and enable Developer mode.
3. Choose **Load unpacked** and select the extracted `KnightScope-v20` folder.

## Scope
This version focuses on post-game review and analysis-board practice. Use analysis tools outside active rated games.

Previous version folders remain preserved.
